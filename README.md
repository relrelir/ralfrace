# 🍭 מרוץ הממתקים (Candy Kart Racers)

משחק מרוצי מכוניות תלת-ממדי לילדים (ולהורים), בעולם של סוכריות – בהשראת המרוץ מ"ראלף ההורס" ומ-Trackmania.
רץ בדפדפן במחשב, בטלפון (PWA) וכאפליקציית אנדרואיד (APK).

## מה יש במשחק
- **10 מסלולים בשני עולמות**: שביל הסוכריות, עמק השוקולד, הר העוגה (שמונה עם גשר), לופ המרשמלו (לופ מלא!), טורנדו הליקריץ, קרחון הגלידה, ג'ונגל הגומי, ענני צמר-גפן (ספירלה בשמיים), מפעל הסוכריות (לופ כפול), הר הגעש של השוקולד.
- **מרוץ** נגד 5 נהגי מחשב, 3 הקפות, עם קופסאות הפתעה: 🚀 טורבו · 🫧 מגן מסטיק · 🍬 מלכודת טופי · 🍭 טיל סוכריה.
- **נגד השעון** בסגנון טרקמניה: הקפה אחת נגד רוח הרפאים של השיא שלך, זמני ביניים (+/−), מדליות 🥉🥈🥇 והתחלה מחדש מיידית (R).
- **2 שחקנים במסך מפוצל** על אותה מקלדת (ותמיכה בשלטים).
- **המוסך**: 8 מכוניות עם נתונים שונים, 7 סוגי גלגלים, 10 קישוטים, 18 צבעים, דוגמאות, גימורים ושובלי טורבו. חלק נפתחים בהישגים (מדליות זהב, גביעים).
- **מטבעות**: אוספים במסלול ומקבלים על מקום/מדליה – פותחים מסלולים וחלקים.
- דריפט עם מיני-טורבו, משטחי טורבו, רמפות, זינוק טורבו בספירה, מוזיקה וצלילים (נוצרים בקוד).
- 3 רמות קושי (בקל ההגה "עוזר" להישאר על המסלול).

## הפעלה מקומית
```bash
npm install
npm run dev        # פותח שרת פיתוח
npm run build      # בונה לתיקיית dist
npm run sim        # סימולציה בלי גרפיקה: זמני הקפה של המחשב בכל המסלולים
npm run check      # בדיקות גיאומטריה למסלולים (סגירה, רדיוס, חפיפות)
```

## פרסום
- **אתר (GitHub Pages)**: כל דחיפה ל-`main` בונה ומפרסמת אוטומטית (`.github/workflows/pages.yml`).
  חד-פעמי: ב-GitHub → Settings → Pages → Source: **GitHub Actions**.
  הכתובת: `https://relrelir.github.io/ralfrace/`
- **אנדרואיד**: כל דחיפה בונה APK (`.github/workflows/android.yml`) – מורידים מ-Actions → הריצה → Artifacts.
  בדחיפה ל-`main` ה-APK מתפרסם גם ב-Releases תחת `apk-latest` – הכי נוח להוריד ישר לטלפון.
  התקנה: לפתוח את הקובץ בטלפון ולאשר "התקנה ממקורות לא ידועים".
- **PWA**: אפשר גם לפתוח את האתר בכרום בטלפון → "הוספה למסך הבית", והמשחק עובד גם בלי אינטרנט.

## שפות
המשחק מזהה את שפת הדפדפן: אנגלית, עברית, ספרדית, פורטוגזית, צרפתית או גרמנית, וברירת המחדל היא אנגלית. אפשר להחליף שפה בהגדרות.
כל הטקסטים נמצאים ב-`src/i18n.js`. השמות בעברית של מסלולים וחלקים נמצאים ליד הנתונים שלהם.

## אתרי משחקים (CrazyGames / Poki)
```bash
npm run build:crazygames   # → dist-crazygames/
npm run build:poki         # → dist-poki/
```
- הגרסאות לפורטלים כוללות את ה-SDK של הפורטל (`src/portal.js`):
  - פרסומת בין מרוצים.
  - כפתור "צפו בפרסומת – מטבעות ×2" במסך התוצאות.
  - אירועי gameplay start/stop ו-happytime.
- הגרסה הרגילה (Pages/APK) נשארת בלי פרסומות.
- אם ה-SDK לא נטען (למשל עם חוסם פרסומות), המשחק ממשיך לעבוד בלי פרסומות.
- כל דחיפה ל-`main` בונה את שתי הגרסאות כקבצי zip (`.github/workflows/portals.yml`): ב-Actions → הריצה → Artifacts → `portal-builds`.
- תמונות לחנות: `node tools/make-covers.mjs http://localhost:4173/ covers` (אחרי `npm run build` ו-`npx vite preview`).

**הגשה:**
1. **CrazyGames:** נרשמים ב-developer.crazygames.com, יוצרים משחק חדש (HTML5), מעלים את `candy-kart-crazygames.zip` ואת התמונות, וממלאים תיאור. הם בודקים (QA) ומחזירים הערות אם יש.
2. **Poki:** מגישים בקשה ב-developers.poki.com עם הקישור לגרסת GitHub Pages. אם מאשרים, מעלים את `candy-kart-poki.zip` דרך הפאנל שלהם.
3. בשני האתרים מסמנים את המשחק כמתאים לילדים. אנחנו לא אוספים מידע אישי (השם נשמר רק בדפדפן).

## מבנה הקוד
| קובץ | תפקיד |
|---|---|
| `src/trackdefs.js` | הגדרת המסלולים בשפת "צב" פשוטה (ישר, פנייה, לופ, טורבו, קפיצה...) |
| `src/trackdata.js` | דגימת המסלול, מערכות צירים (כולל לופים והטיות) |
| `src/trackmesh.js` | בניית הכביש, הקירות, העמודים והקישוטים |
| `src/physics.js` | פיזיקת הקארט (בקואורדינטות מסלול) |
| `src/ai.js` | נהגי המחשב |
| `src/race.js` | ניהול מרוץ, מצלמות, מסך מפוצל, רוח רפאים, תצוגה |
| `src/items.js` | קופסאות הפתעה, מטבעות, טילים ומלכודות |
| `src/audio.js` | מנועים, אפקטים ומוזיקה (WebAudio) |
| `src/main.js` | תפריטים, מוסך, שמירה, זרימת המשחק |
| `src/i18n.js` | תרגומים ל-6 שפות |
| `src/portal.js` | חיבור ל-SDK של CrazyGames / Poki (פרסומות) |

כל הגרפיקה והסאונד נוצרים בקוד – אין קבצי תמונה/שמע חיצוניים. הדמויות והעולם מקוריים (לא דמויות מהסרט).
